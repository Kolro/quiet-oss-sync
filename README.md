# 静默云同步 · Obsidian 插件

版本：0.1.0（试用版）

为 Obsidian 提供阿里云 OSS 多端自动同步，不是 OBS Studio 插件。已经编译，可直接安装；不需要安装 Node.js。未发布到 Obsidian 社区市场。

## 使用体验

- Obsidian 本身自动保存；停笔约 4 秒后上传已保存的修改。
- 应用在前台时约每分钟检查云端；打开仓库、回到应用、恢复网络时触发检查。
- 点击左侧云朵按钮，或命令面板选择“静默云同步：立即同步”，即可手动同步。点击后约等待 1.2 秒，让 Obsidian 先保存。
- 正常自动同步只更新状态，不弹窗；断网后自动退避重试，最长间隔约 15 分钟。
- 同时修改同一文件时保留多个版本到 `_云同步副本`。正文会选择一个一致版本，并提示你合并。它不自动合并句子。
- 删除会同步；其他设备的原文件先备份，再进入 Obsidian 本地 `.trash`。重命名按新建和删除处理。
- 图片、PDF、Canvas 等普通文件也可同步。单文件上限 50 MB；大于上限会显示错误，需移出该附件后重试。
- 不同步隐藏文件／目录、`.obsidian` 设置、插件密钥、`.trash`、`_云同步副本`，也不接管其他插件的数据。

## 快速安装：iPhone、Android 和电脑

建议先在新的测试仓库试用。安装前备份现有笔记，并暂停同一仓库的其他同步方式。

1. 在 Obsidian 的“设置 → 第三方插件／社区插件”中搜索 **BRAT**，安装并启用。
2. 打开 BRAT 设置，选择 **Add beta plugin**，填入 `Kolro/quiet-oss-sync`（或完整仓库地址 `https://github.com/Kolro/quiet-oss-sync`），选择版本 `0.1.0`，然后添加。
3. 在第三方插件列表中确认“静默云同步”已启用，进入它的设置，填写自己的 OSS 连接信息并点击“连接并保存”。

BRAT 从本仓库的 [Releases](https://github.com/Kolro/quiet-oss-sync/releases) 安装编译好的插件；安装用户无需 Node.js。各设备分别安装，保持 Bucket、地域、同步空间名一致即可。新设备使用新的空仓库，先等已有设备上传完成，再连接下载。不要复制其他设备的 `data.json`。

手机端的安装入口已提供，但尚未做 iPhone 或 Android 真机同步验证。手机退出或被系统暂停后不能持续同步，切换设备前请在前台等到“已同步”。

## 电脑手动安装（也可使用 BRAT）

1. 将现有笔记仓库复制一份备份，暂停同一仓库的 Remotely Save、官方 Sync、iCloud 或其他同步方式。
2. 从 [0.1.0 发布页](https://github.com/Kolro/quiet-oss-sync/releases/tag/0.1.0) 下载 `main.js`、`manifest.json`、`styles.css`，放入名为 `quiet-oss-sync` 的文件夹。也可解压安装包，找到其中的同名文件夹。
3. 将整个文件夹放到 **你的仓库/.obsidian/plugins/quiet-oss-sync/**。如果使用自定义配置目录，请换成实际目录。不要再多嵌套一层文件夹。
4. 重启 Obsidian，在“设置 → 第三方插件／社区插件”中启用“静默云同步”。
5. 打开插件设置，填写连接信息，点击“连接并保存”。

**新设备只复制 `main.js`、`manifest.json`、`styles.css`，再单独填写连接信息。不要复制测试仓库 A／B 或其他设备的 `data.json`：其中既有密钥，也有该设备的同步基线；把它复制到空仓库可能触发误删除同步。**

电脑可在文件管理器中手动安装；手机建议使用上面的 BRAT 安装流程，避免手动访问隐藏目录。

## 阿里云准备

创建一个专用的 OSS 通用 Bucket，选择标准存储、本地冗余、私有权限，保留“阻止公共访问”；不需要 ECS、域名、CDN 或传输加速。选按量付费即可。Bucket 的版本控制应保持从未启用的默认状态；已启用后再暂停也不适用，因为本插件依赖 OSS 的禁止覆盖语义。

创建一个专门的 RAM 用户和 AccessKey。可使用随包 `ram-policy.example.json` 创建自定义权限策略：**先把其中所有 `YOUR_BUCKET_NAME` 替换成实际 Bucket 名称**，再绑定到该用户。本插件只需要列举、读取、写入，没有云端物理删除权限。连接检查会写入一个零字节测试对象。

设置示例：

| 设置 | 示例 |
|---|---|
| Bucket 名称 | my-obsidian-notes-xxxx |
| 所在地域 | cn-hangzhou |
| 同步空间名 | my-notes |
| AccessKey ID | RAM 用户的 ID |
| AccessKey Secret | RAM 用户的 Secret |

**本插件直接使用 OSS V4 认证，地域写 `cn-hangzhou`，不用加 `oss-`，也不用填 Endpoint。** 不要照搬 Remotely Save 的地域字段。各端填写同一个 Bucket、地域和同步空间名；本地仓库名可不同。多个仓库用不同的空间名。

先在有完整笔记的电脑连接并完成首次上传，再在第二台设备的新空仓库连接。请逐一测试新增、修改、附件、重命名和删除。已经绑定且产生同步状态的仓库不允许直接更换目的地，避免混合数据。

## 冲突和找回内容

`_云同步副本` 保存两类文件：并发修改版本，以及覆盖／删除前的本地版本。根据文件名和内容挑选需要的文本，复制回原笔记即可再次同步。此目录不会上传。

云端使用 `quiet-sync/v1/同步空间名/` 下的内容块和不可变历史记录，不是普通 Markdown 镜像，也不兼容 Remotely Save 的目录格式。请勿手动编辑这些对象，或给这些对象设置到期自动删除；缺失历史会使插件安全停止。云端历史尚无可视化还原界面，也尚未实现自动清理。当前版本如需维护，应保留完整云端目录。

## 费用

按中国内地标准存储本地冗余约 0.12 元/GB/月、忙时下载 0.50 元/GB 粗估：云端实际占用 1 GB、每月所有设备累计下载 1 GB，约 **0.62 元/月**。上传流量免费，请求在对应免费额度内可不计。价格和额度以控制台为准。

本插件保留历史内容，云端占用可能高于当前仓库大小。比如实际累计存储 3 GB、月下载 1 GB，约 0.86 元。频繁修改大 PDF、反复安装到新设备会增加存储和下载。小文字笔记的历史通常较小。定时检查会产生列表请求；连接新设备还需下载历史元数据。建议设置费用提醒，不必预购大容量资源包。

## 已知边界

- 这是可安装试用版，已做本地自动化测试和编译检查。**2026-11-06 已在 Windows 上使用真实 OSS 和两个独立 Obsidian 测试仓库，验证自动上传、下载、反向修改、附件、重命名及删除同步。手机端、真实断网恢复和真实双端冲突场景尚未验证。** 新设备仍请先用测试仓库验证，并保留独立备份。
- 手机应用退出或被系统暂停时，插件不能在后台持续运行。重新打开后补同步，关闭前请等状态变为“已同步”。
- HTTPS 保护传输，Bucket 应设为私有；本版本不提供端到端加密。RAM 密钥保存在本机插件 `data.json` 中，未做本地加密，不要分享或提交该文件。
- Markdown 使用 Obsidian 原子修改接口避免覆盖新编辑；未保存的编辑会延后更新。二进制附件替换前会再次检查并保留副本，但 Obsidian 二进制接口不提供原子比较更新，外部程序恰好同时写入的情况仍需人工核对副本。
- 大小写或 Unicode 规范形式冲突的路径会暂停同步。部分跨平台非法文件名和隐藏目录会被排除。支持标准公共云地域 Endpoint，不支持自定义域名、OSS 云盒及临时 STS 凭证。
- 一个仓库只能启用一套同步机制。请另外保留独立备份。

## 验证与开发

源码包含 TypeScript 源码、测试、锁定的依赖和构建文件。运行 `npm ci` 安装依赖后，运行 `npm test`（包括类型检查和构建）。2026-11-06 发布前共 29 项测试通过。发布包内 `main.js` 已编译，安装用户无需执行这些命令。

仓库和发布附件不包含 AccessKey、设备的 `data.json` 或个人笔记。MIT 许可证见 [LICENSE](LICENSE)。
